# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.8.x   | :white_check_mark: |
| 1.7.x   | :white_check_mark: |
| < 1.7   | :x:                |

## Reporting a Vulnerability

If you discover a security issue or vulnerability in TgFlow, please do **NOT** open a public issue.

Instead, please email security concerns to:
- **Email**: security@veez.dev

Please include:
- Description of the vulnerability
- Reproduction steps or proof of concept
- Potential impact

We will review your submission and respond within 48 hours.
